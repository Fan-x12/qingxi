# 清析

一个以 **UI 设计与交互体验** 为重点的 Android 学习项目，基于 Kotlin 与 Jetpack Compose 开发，通过视频解析和对话生图场景探索界面布局、过渡动效与操作反馈。

支持 Android 8.0 及以上版本。

## 声明

> **仅供学习交流：本项目主要用于 Android UI 与交互实现的学习和参考，不作为稳定的解析服务提供。**

视频解析依赖夜雨 API、BugPk API 等第三方接口，其可用性、配额和使用范围以服务商条款为准。本项目仅处理用户主动提交的公开链接，不提供登录态抓取、权限绕过或批量采集功能。请尊重内容版权，在获得授权的范围内使用和保存媒体。

## 功能特性

- **对话布局**：消息气泡、结果入场、底部跟随与历史定位，让输入和结果展示保持连贯。
- **交互动效**：抽屉切换、菜单展开与收起、可中断动画及点击反馈。
- **状态反馈**：展示加载、失败、取消和保存进度等状态。
- **媒体体验**：视频倍速、进度拖动、全屏预览，以及图集和实况图展示。
- **场景演示**：支持抖音、快手、小红书公开链接解析，以及通过兼容接口进行对话生图。
- **本地历史**：保留最近 50 条解析记录，支持搜索、查看与删除。

## 使用方式

1. **视频解析**：粘贴公开分享链接并发送，或通过系统分享菜单交给清析处理，完成后可预览和保存媒体。
2. **对话生图**：在设置的“生图接口”中填写 HTTPS 地址、API Key 和模型，保存启用后切换到“对话生图”，输入提示词。
3. **历史与设置**：查看或删除解析记录，根据需要切换解析接口和生图配置。

## 快速开始

下载源码或克隆仓库，使用 **Android Studio、JDK 17、Android SDK 35** 打开项目并完成 Gradle 同步。

**无需密钥即可构建和浏览界面。** 实际解析和生图需要自行配置获得授权的第三方接口，源码不包含账号、密钥或服务额度。

需要体验解析时，参考 `local.properties.example`，在项目根目录的 `local.properties` 中追加自己的密钥，保留 Android Studio 已生成的 `sdk.dir`：

```properties
YRAIN_API_KEY=your_api_key
BUGPK_API_KEY=your_api_key
```

也支持同名环境变量或 Gradle `-P` 参数，读取顺序为：Gradle 参数 → 环境变量 → `local.properties`。项目不提供接口密钥或服务额度；未配置时，对应解析接口会提示缺少密钥。生图接口在应用内配置。

`local.properties` 仅在本地保存，请勿提交真实密钥。分享截图、日志或示例时，请移除账号、认证信息和私人媒体链接。构建时配置的解析密钥会写入 APK，请勿用个人密钥构建公开分发的安装包。

**Windows**

```powershell
.\gradlew.bat :app:assembleDebug
```

**macOS / Linux**

```bash
chmod +x gradlew
./gradlew :app:assembleDebug
```

构建完成后，安装 `app/build/outputs/apk/debug/app-debug.apk`，或直接通过 Android Studio 运行到设备。

## 常见问题

- **提示未配置密钥**：填写对应解析服务的密钥后重新构建；生图密钥在应用内保存后生效。
- **接口不可用**：检查密钥、额度、网络和服务商条款，或在设置中切换接口。本项目不保证第三方服务持续可用。
- **反馈问题**：通过 GitHub Issues 描述复现步骤、Android 版本和预期表现；截图与日志中请隐藏密钥、账号和私人链接。
